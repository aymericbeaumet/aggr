# Project memory

- Item header folding is a direct function of scroll position, with no threshold toggle or timed transition. Scale the title with stable line breaks and a measured height so shrinking cannot trigger a line-wrap jump; the 48px fade follows the same scroll progress. Header, prose, and continuation cards share one reading measure; a leading body rule is hidden beside the header separator.
- Source presentation preserves publisher identity for aggregators and profile paths for channels. Retained sources use persisted metadata for their archive pages even after removal from config; never infer URLs from slugs.
- Article tags come only from configured or upstream labels. An unlabelled HNRSS item has no tags to display.
- Feed previews default on. Explicit `--refresh` can fill missing previews while preserving existing preview bytes and historical blob URLs; ordinary no-op syncs stay unchanged.
- YouTube captions use publicly advertised tracks with bounded requests and timestamp links. Missing or unavailable captions preserve descriptions; extraction without captions is not cached as a successful transcript. No third-party transcript service is involved.
- Refreshing existing dev items requires a one-time `dev --refresh`, followed by normal `dev`; keeping the flag enabled reprocesses feed-present entries every poll. Dev writes only its isolated cache.

- Navigation skips document view transitions on desktop and mobile. Seed Swup with pristine initial HTML before enhancement adds binding flags; share in-flight page requests, cancel unrelated speculation on navigation, and keep prefetch/cache bounds. Cached service-worker HTML renders immediately while refreshing in the background; dev mode disables service workers.
- Relative-date rendering should avoid per-element Intl formatter construction. Exact publication/update timestamps are precomputed into a shared tooltip and localized only on hover/focus; updated dates stay out of visible metadata.
- Metadata separators belong to noninteractive field wrappers, never anchors. Publisher and optional italic via-feed form the source phrase; linked `/category` and the remaining fields use evenly spaced middots. Equal publication/update instants show only publication in the tooltip.
- Pagefind indexes even zero-weight metadata values. Keep display metadata opaque (hex JSON), compact, and precomputed; raw JSON leaks provider names and implementation keys into search matches.
- YouTube article posters are retained as local image assets separately from small feed previews. Explicit refresh backfills missing posters without changing existing body/HTML/preview companions; the article context alone selects the poster.
- YouTube item pages initialize a paused native player (no autoplay); Twitch and Vimeo load after activation. Players use validated embed URLs and minimal iframe permissions. YouTube uses the privacy-enhanced domain and Vimeo uses DNT; Twitch needs the current hostname as its parent. A creator's published poster can differ from the decoded frame shown after playback.
- Feed selection changes only the palette-orange left marker on desktop, immediately and without shifting content; mobile hides the marker. Row padding and separator insets share one CSS variable across both layouts. The new-item background fade is independent of selection.
- Feed separators share one left edge for the whole list and meet the selection bar. Rank-width metadata belongs to the list, not individual rows.
- Retain the metadata lead image even when extraction starts after it; feed thumbnails and article masters serve different purposes. Only show a separate article lead when that image is absent from the body, including equivalent retained masters.
- Shared article cleanup runs on fetch and build so older archives benefit without rewriting stored content. Remove standalone boundary comment controls conservatively; preserve code, quotes, lists, references, and interior prose.
- Source syntaxes are input adapters: multiline URLs and string arrays become `SourceConfig` entries before the shared resolution and deduplication pipeline. Source attributes use TOML values and the existing strict `SourceConfig` schema; do not maintain a second option schema.
