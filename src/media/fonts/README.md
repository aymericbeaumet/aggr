Atkinson Hyperlegible Regular is embedded only for passive SVG rasterization. It is not downloaded
or resolved from the host system at runtime. Source: https://github.com/google/fonts/tree/main/ofl/atkinsonhyperlegible

The unmodified font is distributed under the SIL Open Font License in `OFL.txt`.
Keep `src/theme/static/AtkinsonHyperlegible.LICENSE` in sync so generated sites and the
binary carry the font's license too.
